# 평창꽃순이김치 AI Agent V2

평창꽃순이김치 제조 데이터를 LOT 중심으로 살펴보는 반응형 AI Agent V2입니다. React·TypeScript·FastAPI를 사용하며 기존 Streamlit V1과 원본 DB는 유지합니다. 데스크톱은 현장 내비게이션·업무 화면·AI를 함께 보여주고, 태블릿은 요청 시 AI 패널을 열며, 모바일은 한 번에 한 업무 화면과 하단 내비게이션을 사용합니다.

## 실행

프로젝트 루트에서:

```bash
python3 -m venv .venv-v2
.venv-v2/bin/pip install -r v2/requirements.lock
npm ci --prefix v2/web
npm run build --prefix v2/web
.venv-v2/bin/uvicorn v2.api:app --host 127.0.0.1 --port 8512
```

접속: http://127.0.0.1:8512

V2는 `data/kkotsuni_v2_demo.db`를 별도로 생성하며 `sample_docs/`를 인덱싱합니다. 개발 서버는 `npm run dev --prefix v2/web`로 실행합니다. Vite는 `/api`를 8512로 전달합니다.

## 고객 업무 중심 개선 (2026-10-02)

- 홈에서 **출하 확인·재고 확인·품질 문의**를 누르면 전체 샘플 기록에 바로 질문합니다. 기존에 선택한 LOT가 있어도 전체 업무 조회에 섞이지 않습니다.
- 처음 사용하는 분을 위해 LOT·CCP·PDA의 쉬운 설명과 이용 순서를 제공합니다.
- 답변은 **확인 결과**, **다음 할 일(확인 안내)**, **근거**로 구분합니다. 다음 할 일은 조회한 업무 유형에 따른 일반 확인 안내이며 새로운 판정이나 승인 결과가 아닙니다.
- **답변 복사**와 **보고서 내려받기(.txt)**에 질문·답변 원문·샘플 기준일·조회 시각·다음 확인사항·문서 및 원본 근거를 담습니다. 자동 복사를 사용할 수 없는 환경에서는 수동 복사 영역을 제공합니다. 기존 JSON 근거 저장도 유지합니다.
- 검증: 프런트엔드 빌드, API 테스트 12개, 보고서의 근거·기준일·0값 보존 확인 통과. Chrome에서 재고/출하 업무 시작, LOT 문맥 전환, 복사 성공과 다운로드된 보고서 내용까지 확인했습니다. 실제 유료 AI·음성과 모바일 기기 검증은 포함하지 않았습니다.

## 모바일 반응형 보완 (2026-10-02)

- 모바일 대화는 화면 전체 높이를 사용하고 대상 LOT·답변 방식·추천 질문을 접어 답변 공간을 확보합니다. 진입 시 키보드를 자동으로 열지 않습니다.
- 새 답변은 내용 시작부터 표시합니다. 복사·저장·전송 버튼은 48px 터치 영역을 제공하고, 입력 글자는 16px로 표시합니다.
- Visual Viewport 높이 변화에 맞춰 입력창 위치를 조정하고, 낮은 화면에서는 상단 브랜드와 보조 안내를 접습니다. 가로 모드와 화면 안전 영역도 반영합니다.
- 태블릿 대화는 넓은 본문 영역을 사용합니다. 작은 화면에서도 샘플 기준일을 표시합니다.
- 검증: 빌드 통과. Chrome 화면 크기 320×568, 390×844, 390×400, 767×390, 844×390, 768×1024, 1024×768, 1440×900에서 대화 가로 넘침과 입력창 위치를 확인했습니다. 320px 홈·LOT·자료 화면, LOT 선택·질문 전송·복사, 48px 버튼도 확인했습니다. 실제 iOS/Android 소프트웨어 키보드와 마이크는 별도 기기 검증이 필요합니다.

## 현재 기능

- 현장 주의 항목에서 CCP, 금속검출, 출하 승인 대기, 재고 부족을 확인하고 관련 LOT로 이동합니다. LOT 목록은 검색·공정·상태 필터를 제공하며, 상세 화면에서 확인된 상위 LOT와 실제 CCP·금속검출·이동·출하 기록을 보여줍니다.
- 모바일에서는 현장·LOT·AI·자료 화면을 하단 내비게이션으로 전환합니다. AI 입력 시 내비게이션을 접어 키보드와 전송 입력란을 확보합니다. 작은 화면의 긴 LOT명·근거 문자열은 줄바꿈하며, 터치 주요 버튼은 48px 이상입니다.
- 자료 화면은 지식문서 검색·본문과 허용된 테이블의 페이지별 원본 조회를 제공합니다. AI 패널에는 대화·LOT·음성, 대화 이력·추천 질문이 있습니다.
- 화면 경로는 `#/home`, `#/lots`, `#/lots/{lot_id}`, `#/assistant`, `#/library` 해시 경로를 사용합니다. 브라우저 새로고침과 링크 공유에 경로는 유지되며, LOT/질문 내용이나 대화 내용은 URL에 넣지 않습니다.
- 직접 질문·추천질문·이력 질문이 같은 처리 경로를 사용합니다. LOT 전환·초기화 시 진행 중 응답과 음성을 취소합니다.
- API 키 없는 데모 조회와 서버 키를 사용하는 AI 모드를 구분합니다. 데모 조회는 고정된 기록 검색이며 임의의 원인 분석이나 승인 판단을 하지 않습니다.
- 포장 LOT의 상위 세척 CCP·금속검출·PDA 이동·출하 근거를 함께 조회합니다. 답변의 문서와 원본 레코드를 펼치고 JSON으로 내려받을 수 있습니다.
- 실시간 WebRTC 음성, 발화 종료 감지·끼어들기·음소거·종료, 서버의 읽기 전용 제조 도구와 답변 읽기 경로를 연결했습니다.
- 모바일 자료·질문 패널, 본문 모달, 오류·빈 결과·로딩 상태를 제공합니다.

## AI 연결

`v2/.env.example`을 참고해 루트 `.env`에 필요한 설정을 넣습니다. API 키는 서버에만 저장합니다. `OPENAI_API_KEY`, `OPENAI_MODEL`, `OPENAI_REALTIME_MODEL`, `OPENAI_REALTIME_VOICE`를 환경변수로 설정할 수 있습니다. 기본 모델명은 기준 프로젝트 값이며 계정의 사용 가능 여부는 별도로 확인해야 합니다.

외부에서 유료 AI를 사용하려면 `COCKPIT_ACCESS_TOKEN`이 필요합니다. UI의 접근 코드는 OpenAI 키와 다르며 브라우저 sessionStorage에 보관됩니다. localhost와 로컬 클라이언트가 모두 확인된 요청만 코드 없이 서버 키를 사용할 수 있습니다. 마이크는 HTTPS 또는 localhost에서 사용합니다.

현재 화면에는 조직 로그인·업무 인계 UI가 없습니다. 원본 프로젝트의 업무·계측 서버 모듈은 확장용으로 유지하되, 화면 저장 기능은 파일 내려받기로 제공합니다. `V2_REQUIRE_LOGIN=1`은 서버를 보호하지만 로그인 화면이 연결되기 전에는 일반 화면을 사용할 수 없습니다. `/work/{id}`도 업무 이어보기 완성을 의미하지 않습니다.

## 데이터 범위

모든 제조 기록은 **2026-09-04 샘플**이며 화면에 기준일을 표시합니다. 실시간 운영 데이터가 아닙니다. 문서·규칙은 **미승인**입니다. 농도나 시간은 관측 예시이며 승인 한계기준이 아닙니다. AI가 생산·출하를 승인하지 않으며 담당자가 원본 기록과 현장 기준으로 직접 판단해야 합니다. 발효 예측, 실시간 센서, MES/PDA 실연계, 생산·출하 승인, PostgreSQL 어댑터는 구현 범위에 포함하지 않았습니다. `DATABASE_URL`이 있으면 미연결을 명시하고 시작을 거절합니다.

## 음성·OpenAI 간편 사용

1. 관리자 최초 설정: 프로젝트 루트에서 `.venv-v2/bin/python -m v2.setup_openai` 실행.
   API 키와 선택적 회사 접근 코드를 숨김 입력합니다. 기존 `.env`의 다른 항목은
   유지하고 파일 권한은 소유자 읽기·쓰기로 설정합니다. 키를 채팅에 붙여넣지 마세요.
2. 서버 재시작 후 화면의 **연결 설정 → OpenAI 연결 검사**를 누릅니다.
   서버 키를 브라우저에 전달하지 않으며, 검사는 모델 조회만 수행합니다.
   모델 조회 성공은 실제 응답·음성 품질 또는 결제 한도를 보장하지 않습니다.
3. 채팅 위의 **OpenAI 답변**을 선택하면 AI 분석으로 질문합니다.
4. **눌러서 녹음 → 완료·문자로 변환 → 문장 확인 → 질문 보내기**로 음성 입력합니다.
   최대 60초 녹음하며 변환 실패 시 재시도하거나 취소할 수 있습니다.
5. **실시간 대화**는 마이크 권한을 허용한 후 바로 말합니다. 음소거·종료로 제어하고,
   파일 업로드는 녹음이 어려운 환경에서 사용합니다. 답변 듣기의 재생·중지도 지원합니다.

음성 변환·실시간 대화·AI 답변은 OpenAI API를 사용합니다. 마이크는 HTTPS 또는
localhost에서 사용하며, 생성 음성은 AI 음성입니다. 실제 키를 등록한 유료 호출과
마이크 실기기 검증은 별도로 수행해야 합니다.

연결 구조 참고: https://developers.openai.com/api/docs/guides/voice-webrtc
