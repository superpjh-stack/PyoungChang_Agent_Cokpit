# 평창꽃순이김치 MES·RAG AI Agent Cockpit

평창꽃순이김치 현장에서 확인된 자동버블세척, CCP 기록, 수주 기반 생산계획, PDA 재고이동, 금속검출, 완제품재고와 택배·배송·B2C 출하를 하나의 대화로 연결하는 실행형 Streamlit 프로토타입입니다.

## Agent Cockpit

- 상단: 오늘 생산계획·실적, CCP·금속검출·출하 위험 KPI
- 왼쪽: 새 대화, 최근 질문, 업무별 추천질문
- 중앙: MES/Data Hub 함수와 문서 근거가 함께 표시되는 채팅
- 오른쪽: 선택 LOT의 계보·CCP·금속검출·PDA·승인 상황
- 설정: OpenAI API 키, 모델, 검색결과 수, 지식문서 인덱싱
- Data Hub: 11개 화이트리스트 테이블, 로컬 문서 검색, 샘플 판단규칙 탐색

API 키가 없어도 데모 KPI와 LOT 상황을 확인할 수 있습니다. API 키를 연결하면 추천질문, 과거 질문, 직접입력과 LOT 브리핑이 하나의 대화 경로로 동작합니다.

등록된 로컬 문서는 앱 시작 시 SQLite 데모 DB에 동기화됩니다. 문서와 규칙은 모두 승인상태·담당자·출처를 보존하며, 키가 없더라도 Data Hub 탐색 화면에서 확인할 수 있습니다.

## 범위 구분

### 현장에서 확인된 사항

- 과산화수소와 물량을 관리하는 자동버블세척 필요
- PDA 기반 원재료 이동관리와 완제품재고 통합 필요
- 금속검출기 일지와 생산일지의 클라우드화 필요
- 생산일지를 화이트보드·Excel로 관리하고 MES 데이터가 부족함
- 외국인 직원이 많아 쉬운 작업안내와 승인 번역문 필요
- 택배·거래처 배송·B2C 주문과 완제품재고의 연결 필요
- 저울, 양념대차저울, 냉장고 센서, 자동테이핑기, 피박스세척기, 충진기 연계 검토

### 시제품 가정

- 화면의 제품명·LOT·수량·농도·재고·주문·설비상태는 모두 `demo_data`입니다.
- 자동버블세척기 4대와 금속검출기 2대는 도입 검토 범위를 반영한 데모이며 설치 완료를 의미하지 않습니다.

### 운영 전 확인 필요

- 실제 제품·레시피·공정순서, HACCP 한계기준과 측정방법
- PLC/센서 모델, 통신 프로토콜, 태그, 수집주기와 네트워크 구성
- ERP·쇼핑몰·택배·PDA 인터페이스와 마스터코드
- 사용자 역할, 승인권자, 로그 보존기간, 백업·복구 기준

## 실행

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app.py
```

## 테스트

```bash
python -m pytest -q
```

## Docker 실행

```bash
cp .env.example .env
docker compose up --build
```

브라우저에서 `http://localhost:8501`을 엽니다. 운영 호스트에서는 `.env` 또는 컨테이너 환경변수의 `OPENAI_API_KEY`를 변경한 뒤 앱 컨테이너를 다시 생성해 키를 교체합니다. `.env`와 API 키는 이미지에 복사하지 않습니다.

현재 저장소는 현장 검증 전 SQLite 데모입니다. 실제 운영 전에는 제품·레시피·HACCP 기준과 인터페이스를 확정하고 PostgreSQL/pgvector 운영 저장소로 전환해야 합니다.

모든 제조 함수는 읽기 전용입니다. CCP 판정, 생산계획 확정, 재고조정, 설비제어, 품질보류 해제와 출하는 담당자 승인 없이 실행하지 않습니다.
