# PDA 재고·출하 운영 가이드 예시

> 검증용 초안입니다. 실제 창고코드, 품목코드, 권한, 택배·배송·온라인몰 인터페이스로 교체해야 합니다.

## PDA 이동 원칙

원재료와 완제품을 가져갈 때 품목코드, LOT, 출발 위치, 도착 위치, 수량, 작업자와 시각을 기록한다. 스캔 누락 또는 미확정 이동은 장부재고와 실물재고의 차이 위험으로 표시한다.

## 출하 통제

택배, 거래처 배송, B2C 온라인 주문은 동일한 주문번호와 포장 LOT로 연결한다. CCP·금속검출·품질 승인과 PDA 완제품 입고가 확인되지 않은 출하는 품질·물류 담당자의 승인 전까지 보류한다.
