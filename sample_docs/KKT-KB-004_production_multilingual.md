# 수주 기반 생산계획·다국어 작업안내 예시

- 문서번호: KKT-KB-004
- 개정: 1
- 담당: 생산관리·품질
- 시행일: 현장 검증 전
- 상태: 샘플/미승인
- 검색어: 수주 납기 생산계획 원료부족 외국인 작업자 쉬운한국어 번역 승인

## 절차

주문량, 납기, 우선순위, 원료 가용량과 설비능력을 함께 확인해 계획 후보를 만든다. Agent는 충돌과 대안을 설명하지만 계획을 확정하지 않는다. 외국인 작업자 안내는 공정명·단위·금지행동·이상 보고대상을 쉬운 한국어로 먼저 작성하고, 검토된 번역문만 현장에 배포한다.

## DB 연결 예시

`SO-260904-02`, `PLAN-260904-02`, `RM-CABBAGE`는 데모 예시다.
