# 자동버블세척 CCP 기록·이탈 대응 예시

- 문서번호: KKT-KB-001
- 개정: 1
- 담당: HACCP·품질
- 시행일: 현장 검증 전
- 상태: 샘플/미승인
- 검색어: 자동버블세척 과산화수소 물량 접촉시간 CCP 이탈 재측정

## 목적

원재료 LOT와 세척 LOT, 세척기 ID, 세척수 투입량, 과산화수소 농도, 접촉시간, 작업자와 측정기 교정상태를 한 기록으로 연결한다.

## 절차

주의 또는 이탈이면 투입량과 측정방법을 재확인하고 영향 LOT를 식별한다. 재처리·폐기·공정 재개는 HACCP 또는 품질 담당자가 승인한다. 이 문서의 수치는 실제 한계기준이 아니며 현장 승인 기준으로 교체해야 한다.

## DB 연결 예시

`WASH-260904-01`, `CCP-W-001`, `BUBBLE-01`은 모두 `demo_data`이다.
