# 생산계획·다국어 작업안내 예시

> 현장 검증 전 예시 문서입니다. 실제 제품, 레시피, 인력, 설비능력과 작업언어를 확인해야 합니다.

## 수주 기반 생산계획

주문번호, 채널, 제품, 주문량, 납기, 우선순위와 원재료 가용재고를 확인한 뒤 계획을 작성한다. Agent는 계획 후보와 충돌을 설명하지만 생산계획을 자동 확정하지 않는다.

## 작업안내

외국인 작업자가 이해할 수 있도록 공정명, 주의사항, 측정단위, 금지행동과 이상 발생 시 보고대상을 쉬운 한국어와 현장 확정 번역문으로 제공한다. 자동번역은 승인된 작업표준서를 대체하지 않는다.
