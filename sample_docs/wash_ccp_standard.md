# 자동버블세척 CCP 기준서 예시

> 시제품 검색 검증용 문서입니다. 실제 HACCP 한계기준, 과산화수소 농도, 물량, 접촉시간과 조치 절차로 교체해야 합니다.

## 기록 항목

- 원재료 LOT와 세척 LOT
- 자동버블세척기 ID
- 세척수 투입량과 과산화수소 농도
- 접촉시간, 시작·종료시각, 작업자
- 측정기 교정상태와 측정방법
- 적합·주의·이탈 결과 및 재측정 기록

## 예외 처리

주의 또는 이탈이 발생하면 해당 LOT를 자동 출하하지 않는다. 작업자는 투입량과 측정방법을 재확인하고, HACCP 또는 품질 담당자가 영향 범위와 재처리 여부를 승인한다.
