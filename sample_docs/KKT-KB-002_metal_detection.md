# 금속검출·포장 보류 대응 예시

- 문서번호: KKT-KB-002
- 개정: 1
- 담당: 품질·생산
- 시행일: 현장 검증 전
- 상태: 샘플/미승인
- 검색어: 금속검출 보류 재검사 격리 포장 LOT 출하

## 절차

검출 또는 불합격이 기록되면 해당 포장 LOT를 식별 가능한 상태로 격리한다. 검출기 점검, 표준 시험편 확인, 영향 범위 조사와 재검사 결과를 기록한다. 보류 해제나 출하는 품질 담당자의 승인이 필요하다.

## DB 연결 예시

`PACK-260904-01`, `MD-260904-01`, `METAL-01`, `SHP-260904-01`은 시제품 연결 예시다.
