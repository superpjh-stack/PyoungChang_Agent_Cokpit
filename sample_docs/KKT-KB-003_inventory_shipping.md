# PDA 재고·출하 승인 운영 예시

- 문서번호: KKT-KB-003
- 개정: 1
- 담당: 자재·물류·품질
- 시행일: 현장 검증 전
- 상태: 샘플/미승인
- 검색어: PDA 이동 미확정 안전재고 완제품 출하 품질승인 택배 B2C

## 절차

품목코드, LOT, 출발·도착 위치, 수량, 작업자와 시각을 PDA 이동 기록으로 남긴다. 미확정 이동은 실물과 장부를 대조한다. 출하는 주문번호·포장 LOT·완제품 입고·CCP·금속검출·품질승인을 확인한 후 사람이 승인한다.

## DB 연결 예시

`MV-003`, `FG-MAT`, `SO-260904-03`, `SHP-260904-03`은 모두 데모 데이터다.
